# Carpeta de Imágenes de Productos

## Descripción
Esta carpeta contiene las imágenes de los productos del sistema POS Mujer Mágica.

## Cómo agregar imágenes

### Opción 1: Carga desde la interfaz (RECOMENDADO)
1. Ve a **Gestión de Productos**
2. Haz clic en **+ Nuevo producto** o edita un producto existente
3. En el campo "Imagen del producto", selecciona un archivo desde tu computadora
4. La imagen se cargará y se mostrará en preview

### Opción 2: Copiar archivos manualmente
1. Copia las imágenes de tus productos a esta carpeta
2. Usa nombres como: `prod_001.png`, `prod_002.jpg`, etc.
3. Las imágenes se mostrarán automáticamente en el catálogo

## Formatos soportados
- PNG
- JPG / JPEG
- GIF
- WebP

## Tamaño recomendado
- Ancho: 200-400px
- Alto: 200-400px
- Tamaño de archivo: Máximo 5MB

## Notas
- Las imágenes se pueden cargar directamente desde la interfaz del sistema
- El sistema convertirá las imágenes a formato Base64 para almacenarlas
- No necesitas eliminar imágenes viejas, el sistema las maneja automáticamente
